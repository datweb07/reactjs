# [React JS] Tìm Hiểu Về Props Trong React

## 1. Props Là Gì?

* **Props** là viết tắt của **Properties** (Thuộc tính).
* Trong các bài học trước, chúng ta đã biết Component có tính tái sử dụng cao. Tuy nhiên, nếu chỉ tái sử dụng thông thường thì mọi lần gọi Component đều cho ra nội dung giống hệt nhau.
* **Ý nghĩa của Props:** Giúp chúng ta tùy chỉnh nội dung (hình ảnh, văn bản) hoặc hành vi của mỗi Component trong từng lần gọi khác nhau, tạo ra các giao diện động linh hoạt từ cùng một bộ khung Component.

## 2. Cách Xây Dựng Và Truyền Props Vào Component

### a. Khai báo Component nhận tham số `props`

Thay vì để trống phần tham số của hàm, chúng ta truyền vào một tham số đại diện (thường đặt tên là `props`). Bản chất của `props` trong React là một **Object** chứa các thuộc tính được truyền từ Component cha xuống.

```jsx
// Định nghĩa component MainContent
function MainContent(props) {
    return (
        <li>
            {/* Truy cập thuộc tính của object props bằng dấu chấm */}
            <img src={props.image} alt={props.title} />
            <h2>{props.title}</h2>
            <p>{props.desc}</p>
        </li>
    );
}

```

### b. Gọi Component và truyền giá trị cho Props

Tại Component cha (ví dụ như Component `App`), khi gọi thẻ Component con, chúng ta truyền các thuộc tính vào giống như cách viết thuộc tính trong HTML:

```jsx
function App() {
    return (
        <main>
            <section id="core-concept">
                <ul>
                    {/* Lần gọi thứ 1 */}
                    <MainContent 
                        image={img1} 
                        title="Components" 
                        desc="Thành phần cốt lõi của React..." 
                    />
                    
                    {/* Lần gọi thứ 2 */}
                    <MainContent 
                        image={img2} 
                        title="JSX" 
                        desc="Cú pháp mở rộng của JavaScript..." 
                    />
                </ul>
            </section>
        </main>
    );
}

```

## 3. Cách Khai Báo Import Nhiều Hình Ảnh Bằng Đường Dẫn Tương Đối

Khi sử dụng hình ảnh cục bộ đặt trong thư mục mã nguồn (`src/assets/`), ta cần import từng ảnh như một module trước khi truyền chúng vào Props dưới dạng biến:

```jsx
import img1 from './assets/pic1.png';
import img2 from './assets/pic2.png';
import img3 from './assets/pic3.png';
import img4 from './assets/pic4.png';

```

*Mẹo trong Windows:* Dấu xược của hệ điều hành thường ngược (`\`), bạn cần chuyển thành xược xuôi (`/`) để đường dẫn chạy được trong môi trường Web. Bạn có thể sử dụng tổ hợp phím `Ctrl + Shift + L` trong VS Code để đổi hàng loạt các ký tự giống nhau một cách nhanh chóng.

## 4. Kiểm Tra Và Xác Thực Kiểu Dữ Liệu Với `propTypes`

### a. Lý do sử dụng

Khi làm việc với Props, các extension kiểm tra mã nguồn (như ESLint) thường sẽ đưa ra cảnh báo: *"Missing props validation"*.
Để giải quyết cảnh báo này và đảm bảo dữ liệu truyền vào Component luôn chính xác (ví dụ: yêu cầu phải là chuỗi, số, hay bắt buộc phải có), chúng ta sử dụng thư viện `prop-types`.

### b. Cài đặt thư viện

Tắt ứng dụng đang chạy bằng `Ctrl + C` trong Terminal và chạy lệnh cài đặt:

```bash
npm install prop-types

```

### c. Cấu hình `propTypes` cho Component

1. Tiến hành `import PropTypes` ở đầu file.
2. Khai báo thuộc tính `.propTypes` (viết thường chữ `p` đầu) ngay dưới Component tương ứng.

```jsx
import PropTypes from 'prop-types';

// ... Định nghĩa Component MainContent ở đây ...

// Cấu hình kiểm tra kiểu dữ liệu cho MainContent
MainContent.propTypes = {
    // Kiểu dữ liệu mong muốn là string và bắt buộc phải truyền (isRequired)
    image: PropTypes.string.isRequired,
    title: PropTypes.string.isRequired,
    
    // Kiểu string nhưng không bắt buộc (không có isRequired)
    desc: PropTypes.string 
};

```

> **Lưu ý cú pháp quan trọng:**
> * Khi gắn vào Component: `MainContent.propTypes` (chữ `p` đầu viết thường: **p**ropTypes).
> * Khi gọi từ thư viện để định nghĩa kiểu: `PropTypes.string` (chữ `P` đầu viết hoa: **P**ropTypes).
> 
> 

### d. Cơ chế hoạt động khi truyền sai dữ liệu

Nếu bạn đã quy định `image` phải là `string` nhưng cố tình truyền vào một `Object`:

```jsx
const obj = { name: "Nam", age: 38 };
// Truyền sai kiểu dữ liệu vào component
<MainContent image={obj} title="Test" />

```

Khi mở trình duyệt và nhấn `F5` kiểm tra tab **Console (F12)**, React sẽ ngay lập tức đưa ra cảnh báo lỗi cụ thể để lập trình viên nhận biết dữ liệu truyền vào đang bị sai lệch cấu trúc mong muốn.
