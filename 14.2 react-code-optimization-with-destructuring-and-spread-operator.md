# [React JS] Tối Ưu Hóa Props Với Destructuring Và Spread Operator

## 1. Đặt vấn đề

Trong bài học trước, chúng ta đã dùng Props để truyền dữ liệu vào Component. Tuy nhiên, nếu gọi Component nhiều lần (ví dụ 4 lần) và gõ cứng thủ công từng thuộc tính (`image={...}`, `title={...}`, `desc={...}`), mã nguồn sẽ bị lặp lại rất nhiều và cồng kềnh.

Để giải quyết vấn đề này, có 3 bước tối ưu hóa:

1. Chuyển toàn bộ dữ liệu tĩnh sang dạng mảng các Object (`Array of Objects`).
2. Sử dụng toán tử rải (**Spread Operator - `...**`) để truyền nhanh Props.
3. Sử dụng cú pháp bóc tách dữ liệu (**Destructuring**) tại Component con để code ngắn gọn hơn.

## 2. Quản Lý Dữ Liệu Tập Trung Với Mảng (Array of Objects)

Thay vì viết dữ liệu trực tiếp trong file JSX, ta tổ chức lại file dữ liệu `data.js` bằng cách gom các đối tượng vào một mảng và `export` ra ngoài.

*Lưu ý về đường dẫn: File `data.js` nằm ngoài thư mục `src/`, nên khi import hình ảnh trong `data.js` cần dùng đường dẫn tương đối bắt đầu bằng `./src/assets/...`.*

```javascript
// File: data.js
import pi1 from './src/assets/pic1.png';
import pi2 from './src/assets/pic2.png';
// ... import pi3, pi4 tương tự

export const MyData = [
    {
        image: pi1,
        title: "Components",
        desc: "Thành phần cốt lõi của React..."
    },
    {
        image: pi2,
        title: "JSX",
        desc: "Cú pháp mở rộng của JavaScript..."
    },
    // ... Thêm các phần tử index 2 và 3
];

```

Tại file `app.jsx`, chúng ta import mảng `MyData` này vào để sử dụng:

```jsx
// Sử dụng hai chấm (../) để lùi ra ngoài thư mục cha một cấp tìm file data.js
import { MyData } from '../data.js';

```

## 3. Tối Ưu Hóa Truyền Props Bằng Toán Tử Rải (Spread Operator `...`)

### Cách viết thông thường (vẫn còn dài):

Truy cập dữ liệu qua chỉ số Index của mảng:

```jsx
<MainContent 
    image={MyData[0].image} 
    title={MyData[0].title} 
    desc={MyData[0].desc} 
/>

```

### Cách tối ưu bằng Spread Operator (`...`):

Vì mỗi phần tử `MyData[index]` bản chất là một Object có các key (`image`, `title`, `desc`) trùng khớp với tên các Props cần truyền, ta dùng toán tử `...` để rải toàn bộ các cặp key-value này vào Component.

```jsx
<ul>
    <MainContent {...MyData[0]} />
    <MainContent {...MyData[1]} />
    <MainContent {...MyData[2]} />
    <MainContent {...MyData[3]} />
</ul>

```

*Đoạn mã trên tương đương hoàn toàn với cách viết tường tường minh ở trên nhưng ngắn gọn hơn rất nhiều.*

## 4. Tối Ưu Hóa Component Con Bằng Destructuring

### Cách viết cũ (Sử dụng `props.` lặp lại):

```jsx
function MainContent(props) {
    return (
        <li>
            <img src={props.image} alt={props.title} />
            <h2>{props.title}</h2>
            <p>{props.desc}</p>
        </li>
    );
}

```

### Cách tối ưu bằng Destructuring:

Thay vì nhận toàn bộ object `props` rồi gọi `props.image`, `props.title`, ta bóc tách ngay các thuộc tính cần thiết ngay tại vị trí tham số bằng cặp dấu ngoặc nhọn `{}`.

```jsx
// Áp dụng Destructuring để lấy trực tiếp các thuộc tính
function MainContent({ image, title, desc }) {
    return (
        <li>
            <img src={image} alt={title} />
            <h2>{title}</h2>
            <p>{desc}</p>
        </li>
    );
}

```

> **Mẹo trong VS Code được nhắc tới:**
> Nếu muốn xóa nhanh chữ `props.` ở nhiều dòng giống nhau, bạn có thể bôi đen chữ `props.`, nhấn tổ hợp phím `Ctrl + Shift + L` để chọn tất cả các vị trí trùng lặp, sau đó nhấn nút `Delete` để xóa đồng loạt.
